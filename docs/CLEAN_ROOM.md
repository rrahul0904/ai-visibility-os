# Clean-room Implementation Notes

This repository implements general product ideas visible in the AI-discovery/GEO software category. It intentionally avoids copying third-party source code, private endpoints, protected assets, credentials, database contents or non-public implementation details.

Publicly observable concepts are translated into independently designed domain contracts and workflows. The UI is original rather than pixel-matched. Provider and CMS integrations use public APIs/adapter boundaries and must comply with each provider's terms before production use.
