# Product Specification

## Product thesis

AI-search monitoring alone will commoditize. The durable product is a closed loop that **observes → explains → prioritizes → executes → remeasures**.

## Personas

- Head of Growth / SEO: needs visibility, competitor and citation gaps.
- Content lead: needs evidence-backed briefs instead of generic AI content.
- Founder: needs a small set of high-impact actions and proof that they worked.
- Agency: needs multi-project portfolio operations and client-ready evidence.

## Core workflows

### 1. Onboard a brand
Domain → crawl/describe → detect category → suggest competitors → generate buyer prompts → approve monitoring portfolio.

### 2. Monitor buyer prompts
Schedule prompt/provider runs. Store full answer, timestamps, model/provider identity and citations before analysis.

### 3. Explain the answer environment
Extract own-brand presence, competitors, order/rank, citation sources and recurring source domains.

### 4. Find gaps
Combine missing-brand runs with competitor wins, citation patterns and commercial prompt scores.

### 5. Execute
Create actions such as article, comparison page, page refresh, redirect fix, third-party citation campaign or community/review placement.

### 6. Publish
Idea → brief → draft → approval → schedule → publish → publication URL.

### 7. Attribute
After intervention, rerun matched prompts and compare visibility/citation metrics to the pre-intervention baseline.

## Non-goals for first release

- copying any third-party UI or proprietary implementation
- claiming causal attribution from simple before/after correlation
- auto-publishing without explicit workspace controls
- using one opaque LLM score as the source of truth
